# TreeTalk Obsidian Plugin

**Version**: 0.9.5  
**Author**: Len_shan

Native Markdown tree conversations with deliberate knowledge capture.

## Installation

1. Download `treetalk-v0.9.5.zip`
2. Extract to `.obsidian/plugins/TreeTalk-Obsidian/` in your vault
3. Enable the plugin in Obsidian settings

## Files

- `main.js` — Plugin core logic (577KB)
- `manifest.json` — Plugin metadata
- `styles.css` — UI styles (31KB)
